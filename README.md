# Postman API

Колекції:
- **imperative-api.json** — демонстрація послідовного (імперативного) підходу
- **asynchronous-api.json** — демонстрація асинхронного підходу
- **jsonplaceholder-env.json** — середовище для виконання запитів (JSONPlaceholder)

Запускати у Postman Collection Runner або окремо.
